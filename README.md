# 🌿 Vegan Bulk Tracker

A daily nutrition and training log built for vegan Olympic weightlifters on a bulk. Tracks meals, macros, water, supplements, bodyweight progress, and lifting numbers — all in a single offline-capable HTML file.

## ✨ Features

- **Smart meal plans** — separate training day (3,050 kcal) and rest day (2,600 kcal) menus that switch automatically based on the day
- **Live macro tracking** — real-time progress bars for calories, protein, carbs, and fat as you check off meals
- **Water intake** — tap-to-fill cups tracking up to 3.5L
- **Supplement checklist** — Creatine, B12, D3+K2, Zinc, Omega-3, Iodine
- **Bodyweight progress bar** — tracks your journey from 69 kg → 80 kg
- **Lifting log** — log Snatch, Clean & Jerk, Front Squat, Back Squat, Deadlift, Push Press
- **Daily notes** — energy, sleep, recovery notes
- **Date navigation** — browse and log any past or future day
- **Persistent storage** — data saved to localStorage, survives page refreshes
- **Light / Dark mode** — toggle with one click

## 🥗 Nutrition Targets

| | Training Day | Rest Day |
|---|---|---|
| Calories | 3,050 kcal | 2,600 kcal |
| Protein | 180g | 130g |
| Carbs | 420g | 366g |
| Fat | 80g | 65g |

All meals are **100% plant-based** using staples like soya milk, pea & brown rice protein, sattu, rajma, dal, oats, peanut butter, and soya chunks.

## 🚀 Usage

No install, no dependencies, no build step.

````bash
git clone https://github.com/tijaruS/Vegan-mealplan.git
cd Vegan-mealplan
# Open index.html in any browser
````

Or just open `index.html` directly — it works completely offline.

## 🏋️ Built For

- 179 cm / 69 kg → 80 kg bulk target
- Olympic weightlifting (6 days/week training)
- Vegan / plant-based diet
- Training sessions: Tue–Sun, 6:30–9:00 PM
- Rest day: Monday (active recovery)

## 🛠️ Tech

Pure HTML, CSS, and vanilla JavaScript. Zero dependencies, zero frameworks, zero build tools. Data persists via `localStorage`.
